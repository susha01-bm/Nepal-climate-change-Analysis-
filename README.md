# Nepal Daily Climate Data Analysis (1981–2019)

Hi everyone! This is my 1st data analysis project using Python. I have successfully completed the analysis and want to share my findings!


## Project Overview
Climate change is a massive environmental challenge worldwide. Nepal is experiencing rapidly changing temperatures and rainfall patterns. This project analyzes daily climate data from 1981 to 2019 to find long-term trends.


## Project Objectives
* Cleaned and explored a real-world daily climate dataset.
* Analyzed long-term temperature trends and rainfall patterns.
* Compared climate variations across different districts and provinces.
* Studied seasonal changes using exploratory data analysis (EDA).
* Built interactive visualizations to make the data easy to understand.


## Tools & Libraries Used
* **Pandas & NumPy** - For data manipulation.
* **Plotly** - For interactive charts.
* **Matplotlib** - For static visualizations.
* **Statsmodels & SciPy** - For checking statistical trends.


## Project Workflow
1. **Data Cleaning:** Removed duplicate records and handled missing values.
2. **Feature Engineering:** Created time-based features (Year, Month, Season) from daily dates.
3. **Exploratory Data Analysis (EDA):** Calculated averages, highs, and lows across decades.
4. **Data Visualization:** Built trend lines and regional comparisons.
